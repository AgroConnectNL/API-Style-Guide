### <a id="p004"></a>[P004] Schema names **MUST** be CamelCase (PascalCase)

All schema names MUST be CamelCase (a.k.a PascalCase) matching regex `^[A-Z][a-z\d]*([A-Z][a-z\d]*)*$`
